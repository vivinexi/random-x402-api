
# Random Data API

A simple paid API powered by FastAPI and x402.

## Features

- Random number generator
- Random inspirational quotes
- HTTP health check
- x402 payment integration
- Base Mainnet
- USDC payments

## Endpoints

GET /health
GET /random?count=3
GET /quote

## Payment

Network: Base Mainnet
Protocol: x402 v2
Currency: USDC
Price: $0.001 per request

## Hosting

Deployed using Render.
